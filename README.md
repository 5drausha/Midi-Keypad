# Midi-Keypad

This week, I decided to make the starter project, the MIDI keypad. 
<img width="840" height="715" alt="image" src="https://github.com/user-attachments/assets/3bab4ca5-cfb0-4b6d-8c82-9e221763a0ac" />

This is my final render of the project. 
This project is slightly tweaked compared to the starter guide. It has 10 piano keys, a rotary encoder. 2 MX switches, a passive buzzer, and an ESP32-S3-Zero. I changed it a little bit because of the pricing of the parts in the tutorial and also to make something that is more practically useful. The rotary encoder will be used for volume control, the buzzer can be used for playing the music from the piano, and the switches can be used to switch modes or key tones.
I haven't made any firmware for this project yet, so I am just going to use the firmware used in the tutorial.
